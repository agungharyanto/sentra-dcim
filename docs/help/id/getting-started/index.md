# Memulai

## Masuk

Saat membuka Sentra DCIM, browser meminta **nama pengguna** dan **kata sandi**. Mintalah kredensial ini kepada
administrator Sentra DCIM. Browser mengingatnya sampai jendela ditutup.

> Cara masuk ini **sementara** sampai fitur login dan peran pengguna (Auth) hadir di v0.3. Halaman ini akan
> direvisi saat itu (catatan internal ISS-026).

Setelah masuk, Anda langsung dibawa ke [Dasbor](../dashboard/index.md).

## Navigasi

- **Sidebar kiri** berisi semua menu, dikelompokkan: Pemantauan, Infrastruktur, Operasional, dan Sistem.
- Menu bertanda **Segera hadir** belum bisa dipakai; membukanya menampilkan penjelasan singkat modul tersebut.
- Tombol di pojok kiri bawah **menciutkan sidebar** menjadi ikon saja; arahkan kursor atau fokus ke ikon untuk
  melihat nama menu. Pilihan ini diingat browser.
- Di ponsel atau tablet, buka menu lewat tombol **☰** di kiri atas, lalu tutup dengan **Esc** atau tombol ×.
- Di bawah judul halaman ada **jejak lokasi** (breadcrumb), misalnya *Sentra DCIM › Pemantauan › Dasbor*.

## Bahasa, tema, dan jam

- **ID/EN** — mengganti bahasa tampilan. Pilihan disimpan di browser ini.
- **Gelap / Terang / Ikuti sistem** — mengganti tema. Tema gelap adalah bawaan.
- **Jam** di header memakai zona waktu yang ditetapkan untuk Sentra DCIM (bawaan WIB), bukan zona waktu
  perangkat Anda. Semua data tetap disimpan dalam UTC.

## Keyboard

- Tekan **Tab** sekali setelah halaman terbuka untuk memunculkan tautan **Lompat ke konten**.
- Semua menu, tombol, dan dialog bisa dipakai dengan **Tab**, **Enter**, dan **Esc**.
