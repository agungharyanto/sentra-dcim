# Dashboard

## Purpose

The Sentra DCIM home page: an overview of the data center — power, environment and alarms — for NOC staff and
facility managers.

**No devices or simulators are connected yet**, so the Dashboard only shows **No devices connected yet**, without
sample numbers or charts. Data appears once the Telemetry Ingestion module ships (v0.6).

## Who can use it

| Action | Who |
|---|---|
| View the Dashboard | Every signed-in user |

## Steps

1. After signing in you are on the Dashboard. From other pages, choose **Dashboard** in the **Monitoring** group.
2. Navigation, language, theme and the clock are explained in [Getting started](../getting-started/index.md).

## Troubleshooting

- **Page not found** — the address does not exist; use the sidebar or **Back to Dashboard**.
- **Something went wrong** — the page failed to render, but the sidebar still works for moving to another page.
  If it repeats, report it with the application version (see the [Help Center](../help/index.md)).
