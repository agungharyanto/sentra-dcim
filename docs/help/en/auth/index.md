# Account & sign-in

Every Sentra DCIM user has **their own account** (username or NIP and a password). Every action is recorded under
that account in the audit log, so never share an account.

| Topic | Content |
|---|---|
| [Signing in and out](login.md) | How to sign in, error messages, locked accounts, signing out |
| [Change password](ganti-password.md) | The first password (must be changed) and voluntary changes |
| [My sessions](sesi.md) | See the devices that are signed in and revoke them |

## Who can use it

| Action | Who |
|---|---|
| Sign in, sign out, change own password, manage own sessions | Every user with an account |
| Create the first or an emergency administrator account | Server operations staff (not through the application) |
| Create, edit, disable users, assign roles, reset other users' passwords | Admin, in the [Users & Roles](../users/index.md) menu |
