## Reboot (dilakukan pemilik)
1. Backup boot volume di OCI Console (sudah direncanakan pemilik).
2. Buka **Serial Console** (OCI Console → Instance → Console connection → Launch Cloud Shell connection) dan biarkan
   terbuka untuk melihat menu GRUB — runbook `docs/ops/runbooks/kernel-rollback.md`.
3. Dari SSH: `sudo systemctl reboot`.
4. Normal: menu GRUB 10 detik → boot otomatis ke **Ubuntu** (kernel 7.0). Bila 7.0 gagal: pilih
   *Advanced options for Ubuntu* → *Ubuntu, with Linux 6.17.0-1020-oracle* (Ctrl+N/Ctrl+P bila panah tidak terkirim).
