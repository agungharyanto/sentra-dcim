# Help Center — English

This folder holds the **English** Help Center pages. Indonesian is the mandatory reference language: every page here
mirrors a page in [`../id/`](../id/README.md) with the **same file name**. From v0.2.4 the UI shows the page that
matches the active language.

> Status v0.2.1: skeleton only. Pages are added in v0.2.4.

## Conventions

- Path: `docs/help/en/<module>/<feature>.md`, mirroring `docs/help/id/<module>/<feature>.md`.
- Sections: purpose, required role, steps, related API endpoints (same template as the Indonesian page).
- Button and menu names must match the labels in `web/src/i18n/locales/en/*.json`.
- No secrets, passwords, admin IPs or key fingerprints.
