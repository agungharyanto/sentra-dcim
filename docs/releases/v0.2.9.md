## Temuan proses sprint v0.2

- **ISS-034 — ban IP yang salah.** (1) Uji ban dari container Docker mem-ban IP gateway bridge karena MASQUERADE →
  uji memakai network namespace. (2) `make test-ui` dengan password salah mem-ban **IP publik server** (setiap cek
  ber-auth terhitung; trafik server ke domainnya lewat hairpin NAT OCI) → probe kredensial fail-fast di `ui.sh` &
  `run.sh`; klaim keliru di runbook dikoreksi.
- **ISS-035 — hasil test dari kode belum di-commit.** Run `test-ui` pemilik 2026-10-13 23:12:27 memakai `ui.sh` di
  working tree server yang sedang diedit (belum di-commit; commit `bdd9fe8` 23:15:26) → **43** cek (acuan 41): blok
  health+version tereksekusi dua kali dari proses curl yang sama (paling mungkin: bash membaca skrip per offset byte
  sementara file ditulis ulang). Build app saat itu bersih. **Pencegahan (CLAUDE.md aturan 13):** edit di git worktree
  terpisah, test pemilik hanya setelah commit+push, skrip dibungkus `main "$@"`, baris pertama output = commit +
  clean/DIRTY. Diterapkan sejak v0.2.9 (worktree `/opt/sentra-worktrees/v0.2.9`; baris sumber terlihat di CI dan run
  pemilik `(clean)`).
- **ISS-031 — supply chain.** pnpm menulis pengecualian `minimumReleaseAge` otomatis (rilis 6–20 jam ter-deploy di
  v0.2.1) → dicabut, dipatok ke rilis > 24 jam, penjaga `supply:check` di CI & build.
- **ISS-033 — CVE nyata** di `golang.org/x/text` ditemukan begitu govulncheck dipasang → diperbaiki.
- **Pemeriksaan visual menangkap bug yang lolos test & axe** (v0.2.3 sidebar ciut kehilangan gaya, label terpotong;
  v0.2.4 deskripsi OpenAPI mentah; v0.2.5 warna sukses tertimpa hover) → jadi langkah wajib (aturan 2).
- **Kesalahan selama v0.2.9:** di worktree `.env` adalah symlink milik admin → full regression sempat menjalankan
  backup sebagai `ubuntu` (12 cek gagal) → `stat -L`. Satu run terbuang karena edit gagal tidak diperiksa sebelum test.
