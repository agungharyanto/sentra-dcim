# Pusat Bantuan

Pusat Bantuan berisi panduan memakai Sentra DCIM, dalam Bahasa Indonesia dan English.

## Cara memakai

1. Pilih halaman dari **daftar di sebelah kiri** (di layar kecil: di atas konten).
2. Ketik di kotak **Cari** untuk menyaring halaman berdasarkan judul dan subjudul.
3. Dari halaman mana pun, tekan tombol **?** di header untuk membuka bantuan halaman yang sedang Anda lihat.
   Bila halaman itu belum punya bantuan khusus, Pusat Bantuan ini yang terbuka.
4. Ganti bahasa dengan tombol **ID/EN** di header; halaman bantuan ikut berganti bahasa.
