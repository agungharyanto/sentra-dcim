## Temuan penutup sprint

- **ISS-046 — `.env` 0640.** Contoh perintah pengisian `MFA_ENC_KEY`/`DB_APP_PASSWORD` memakai `chmod 640`; file
  baru juga mewarisi default ACL direktori repo. Akses efektif hanya baca, tetapi grup `sentra` ikut membaca.
  Diperbaiki dan kini **ditegakkan**: `make up` dan `make release` menolak `.env` yang bukan 0600 (+ ACL baca admin).
- **ISS-045 — ban test vs restart fail2ban.** Hardening di regresi me-restart fail2ban bila `ignoreip` berubah (IP
  sesi SSH admin aktif ikut di-whitelist); jail `backend = polling` melewatkan baris log sebelum polling pertama.
- **ISS-047 — dua flake CI** pada langkah yang tidak berubah (health API setelah jendela pemeliharaan; sertifikat
  internal Caddy belum terbit). Tes kini menunggu kondisi siap; dipantau di v0.4.
- `post-reboot-check` masih menuntut kernel 6.17 terpasang — basi setelah pensiun kernel; diperbaiki sebelum regresi.
