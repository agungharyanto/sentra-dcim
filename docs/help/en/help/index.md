# Help Center

The Help Center contains guides for using Sentra DCIM, in Bahasa Indonesia and English.

## How to use it

1. Pick a page from the **list on the left** (on small screens: above the content).
2. Type in the **Search** box to filter pages by title and subheading.
3. From any page, press the **?** button in the header to open help for the page you are on. If that page has no
   dedicated help yet, this Help Center opens.
4. Switch language with the **ID/EN** buttons in the header; the help page switches language too.

## Reporting a problem

Include the **application version** (shown at the bottom of the sidebar), the page address and the steps you took.
