# Dasbor

## Tujuan

Halaman utama Sentra DCIM: ringkasan kondisi data center — daya, lingkungan, dan alarm — untuk tim NOC dan
pengelola fasilitas.

Saat ini **belum ada perangkat atau simulator yang terhubung**, sehingga Dasbor hanya menampilkan pesan
**Belum ada perangkat terhubung**, tanpa angka atau grafik contoh. Data mulai tampil setelah modul
Telemetry Ingestion (v0.6).

## Siapa yang bisa memakai

| Aksi | Siapa |
|---|---|
| Melihat Dasbor | Semua pengguna yang sudah masuk |

## Langkah

1. Setelah masuk, Anda otomatis berada di Dasbor. Dari halaman lain, pilih **Dasbor** di grup **Pemantauan**.
2. Navigasi, bahasa, tema, dan jam dijelaskan di [Memulai](../getting-started/index.md).

## Pemecahan masalah

- **Halaman tidak ditemukan** — alamatnya tidak ada; gunakan sidebar atau tombol **Kembali ke Dasbor**.
- **Terjadi kesalahan** — halaman gagal tampil, tetapi sidebar tetap bisa dipakai untuk pindah halaman. Bila
  berulang, laporkan beserta versi aplikasi (lihat [Pusat Bantuan](../help/index.md)).
